# VLSI Engineering Portfolio

Professional portfolio of T. Maharshi Sanand Yadav.

## GitHub Pages

1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then Save.
4. After the Pages deployment completes, visit: https://t-maharshi-sanand-yadav.github.io/vlsi-portfolio/

## Unlisted-link preference

This site includes `noindex` metadata and a `robots.txt` disallow rule to discourage search indexing. GitHub Pages is still publicly accessible to anyone who knows or receives the URL. These settings are not authentication or access control.
